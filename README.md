# Terminal-Painter
A Java project that lets a user paint into their terminal using traditional mouse input.
<img width="771" height="539" alt="image" src="https://github.com/user-attachments/assets/acdbb4e6-2e77-4583-a488-807eb164f6b7" />

## Interactive Terminal Screen
This project uses [Lanterna](https://github.com/mabe02/lanterna), a Java package that enables gathering
user input, such as from a mouse or keyboard, as events to act upon.

The program allows the user to use mouse clicking and dragging to paint on the canvas.
The canvas is variable to the size of the user terminal, up to a maximum canvas size of 94x94.

A user may also save the canvas as a .txt file!
